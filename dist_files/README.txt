======================================================================
CP3000 波形ビューワー 使い方説明書
======================================================================

CP3000 の測定データ (prof*.dat / *CSV_data.csv / LOG*.dat) を読み、
凝固波形（生波形・100%正規化・速度波形・加速度波形）および比色波形
（吸光度変化・吸光度変化率）をブラウザで高速に確認・解析できるアプリです。
Python のインストールや設定は不要で、生データのフォルダには何も書き込みません。


1. 初回の準備 (zip の展開と置き場所)
----------------------------------------------------------------------
(1) 配布された zip ファイル (CP3000Viewer_<版>_full.zip) を右クリックし、
    「すべて展開...」を選んで展開してください。
    ※ zip を展開せずに中の bat をダブルクリックしても動きません。

(2) 置き場所のおすすめ:
    C:\Users\<あなたの名前>\CP3000Viewer
    など、OneDrive で同期されないローカルフォルダに置いてください。
    (OneDrive の「デスクトップ」や「ドキュメント」に置くと、数千個の
     ファイルの同期が走り、動作が遅くなる場合があります)


2. 起動と終了のしかた
----------------------------------------------------------------------
【起動】
  フォルダ内の「start_viewer.bat」をダブルクリックしてください。
  黒い画面が開き、数秒後にブラウザ (Edge / Chrome) で
  http://localhost:8000 が自動的に開きます。

  ※ 初回は合成デモデータ (demo_data) または data-source が表示されます。
  ※ ブラウザを閉じてしまった場合は、もう一度「start_viewer.bat」を
    ダブルクリックするか、ブラウザで http://localhost:8000 を開いてください。

【終了】
  起動時に開いた黒い画面 (コマンドプロンプト) を閉じると、
  ビューワーが終了します。


3. 測定データの配置と読み込み
----------------------------------------------------------------------
【測定データの配置（推奨）】
  本アプリと同じフォルダにある「data-source/」フォルダの中に測定データを
  配置してください。以下の2つの形式に対応しています。

  ① バッチフォルダ形式 (推奨: 3点セット):
      data-source/
        └─ batch_20261106_01/
             ├─ prof01.dat         (必須: 生波形データ)
             ├─ 261106CSV_data.csv (必須: 測定結果CSV)
             └─ LOG01.dat          (任意: 装置ログ)

  ② CSVファイル単体形式:
      data-source/
        └─ 250326CSV_data.csv      (CSV内に波形データがある比色項目など)

【画面からの読み込み】
  ・画面右側のサイドバーでデータを選択します。
    - 「📁 data-source」ボタン: data-source 内のバッチ・CSVを読み込みます。
    - 「🧪 demo_data」ボタン: デモデータフォルダにワンクリックで切り替えます。
    - 共有フォルダや外部ドライブにあるデータを読み込みたい場合は、
      「親フォルダ」欄にフルパス (例: D:\CP3000_Data) を入力してください。
  ・サイドバー右上の「×」ボタン、または画面右上の「設定パネル」アイコンで
    サイドバーを開閉し、グラフを画面いっぱいに広く表示できます。


4. 波形の見かたと便利機能
----------------------------------------------------------------------
・画面上部のタブで表示を切り替えられます。
  - 「重ね描き」:
      一覧表でチェックを入れた波形（複数選択可）を重ねて比較できます。
      ドラッグ選択や Shift+クリックでの一括選択にも対応しています。
      比色項目の場合は「0点の基準ポイント（何秒目を0にするか）」を選択でき、
      グラフ上に青い破線で基準点が表示されます。
  - 「1波形の詳細」:
      選択した1検体の各波形パネルと、Te/Tc、測定値、基準点情報を確認できます。
  - 「一覧・読み込み情報」:
      全波形のデータ一覧の確認や CSV エクスポート、読込ファイルの確認ができます。


5. 新しい版への更新 (アップデート)
----------------------------------------------------------------------
(1) ビューワーが起動している場合は、黒い画面を閉じて終了してください。
(2) 「update_viewer.bat」をダブルクリックしてください。
    - 自動的に GitHub Releases を確認します。
    - 新しい版がある場合は「アップデートしますか？ [Y/n]」と表示され、
      Y を押すだけで自動的に更新パッケージをダウンロードして入れ替えます。
      (保存済みのユーザー設定はそのまま引き継がれます)
    - すでに最新の場合は、その旨を表示して数秒後に自動で画面が閉じます。

※ 社内共有フォルダから更新したい場合は「user\update_source.txt」を
  メモ帳で開き、共有フォルダのパスを 1 行で記入してください。
※「全体の入れ替えが必要です」と表示された場合は、ブラウザが開くので
  新しい full.zip をダウンロードして展開し直してください。


6. 困ったときは
----------------------------------------------------------------------
・「先に zip をすべて展開してください」と出る
  → zip ファイルの中を直接開いています。zip を右クリックして
    「すべて展開...」してから、展開先の start_viewer.bat を開いてください。

・起動に失敗する
  →「user\last_error.log」にエラー内容が記録されます。
    開発者に「user\last_error.log」と「VERSION.txt」の内容をお知らせください。
