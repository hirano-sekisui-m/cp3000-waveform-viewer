======================================================================
CP3000 波形ビューワー 使い方説明書
======================================================================

CP3000 の生データ (prof*.dat / *CSV_data.csv / LOG*.dat) を読み、
生波形・凝固波形・速度波形・加速度波形をブラウザで確認するアプリです。
Python のインストールやインターネット接続は不要です。
また、生データのフォルダには何も書き込みません。


1. 初回の準備 (zip の展開と置き場所)
----------------------------------------------------------------------
(1) 配布された zip ファイル (CP3000Viewer_<版>_full.zip) を右クリックし、
    「すべて展開...」を選んで展開してください。
    ※ zip を展開せずに中の bat をダブルクリックしても動きません。

(2) 置き場所のおすすめ:
    C:\Users\<あなたの名前>\CP3000Viewer
    など、OneDrive で同期されないローカルフォルダに置いてください。
    (OneDrive の「デスクトップ」や「ドキュメント」に置くと、数千個の
     ファイルの同期が走り、動きが遅くなります)


2. 起動と終了のしかた
----------------------------------------------------------------------
【起動】
  フォルダ内の「start_viewer.bat」をダブルクリックしてください。
  黒い画面が開き、数秒後にブラウザ (Edge / Chrome) で
  http://localhost:8510 が自動的に開きます。

  ※ 初回は合成デモデータ (demo_data) が表示されます。
  ※ ブラウザを閉じてしまった場合は、もう一度「start_viewer.bat」を
    ダブルクリックするか、ブラウザで http://localhost:8510 を開いてください。

【終了】
  起動時に開いた黒い画面 (コマンドプロンプト) を閉じると、
  ビューワーが終了します。


3. データの見かた
----------------------------------------------------------------------
・画面左のサイドバー「データ」で読み込み方法を選べます。
  - 「フォルダから選ぶ」:
      親フォルダ (例: E:\CWA\data\raw) を入力すると、その下 (3階層まで)
      にある prof*.dat を含む測定バッチを一覧から選べます。
      一度入力した親フォルダは user\settings.json に自動保存され、
      次回も同じフォルダが開きます。
  - 「ファイルをアップロード」:
      prof*.dat・*CSV_data.csv・LOG*.dat をまとめて選んで開けます。

・画面上部の 3 つのタブで表示を切り替えられます。
  - 「重ね描き」: 一覧で選んだ波形 (Ctrl / Shift で複数選択) を重ねて比較
  - 「1波形の詳細」: 1つの波形の 4 パネル表示と Te / Tc・装置測定値の確認
  - 「一覧・読み込み情報」: 全波形の一覧 (CSV 保存可) と読込ファイルの確認


4. 新しい版への更新 (アップデート)
----------------------------------------------------------------------
(1) ビューワーが起動している場合は、黒い画面を閉じて終了してください。
(2) 「update_viewer.bat」をダブルクリックしてください。
    共有フォルダの最新版を確認し、アプリ部分 (app フォルダ) だけを
    自動で入れ替えます。保存済みの設定 (user\settings.json) は消えません。

※ 共有フォルダの場所を変える場合は「user\update_source.txt」を
  メモ帳で開き、共有フォルダのパスを 1 行で記入してください。
※「全体の入れ替えが必要です」と表示された場合は、共有フォルダが開くので
  新しい CP3000Viewer_<版>_full.zip をコピーして展開し直してください。
  (元の user\settings.json を新しい user\ にコピーすると設定を引き継げます)


5. 困ったときは
----------------------------------------------------------------------
・「先に zip をすべて展開してください」と出る
  → zip ファイルの中を直接開いています。zip を右クリックして
    「すべて展開...」してから、展開先の start_viewer.bat を開いてください。

・起動に失敗する
  →「user\last_error.log」にエラー内容が記録されます。
    開発者に「user\last_error.log」と「VERSION.txt」の内容をお知らせください。
